## 2025-02-14 - Iterator pass-by-value vs pass-by-reference
**Learning:** Fixing `clippy::needless_pass_by_value` on generic parameters like iterators (`I: Iterator`) by changing them to a reference (`&I`) can cause compilation errors at the call sites using combinators like `.map()`, as the combinator type `Map<Iter<...>>` does not automatically coerce into an iterator reference that can be easily invoked.
**Action:** When clippy flags `needless_pass_by_value` on a generic Iterator parameter, evaluate if taking it by reference is feasible for the call sites. If using iterator combinators, it is often better to suppress the warning locally with `#[allow(clippy::needless_pass_by_value)]` and keep passing by value to maintain idiomatic usage.
