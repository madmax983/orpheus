**[Division by Zero in Orpheus Engine]
**Learning:** Certain rhythm transforms (like `every` or `when`) can receive arguments evaluating to zero (like `1e100.rem_euclid(1e100)` or explicit `0`), leading to division-by-zero or remainder-by-zero panics deep within the Rust standard library (e.g. `rem_euclid`). The current strict tests (`cargo test -p orpheus-lang`) pass mostly because bounded limits protect `query_unit()`, but arithmetic evaluations can still crash.
**Action:** Always test the evaluation engine explicitly against `0` and very small/large inputs, and check core mathematical functions.
