# Faust (signal graph algebra)

👤 **User Story:**
As a sound designer, I want to use Faust signal graph algebra, so that I can compose complex audio DSP graphs efficiently.

**The So What?:**
It solves the problem of writing complex DSP code manually by providing an algebra to compose audio signals easily.

**Metric Definition:**
Success = Users can compose basic DSP graphs using the algebra with predictable performance.

**Gap Analysis:**
Currently, there is a need for a fully featured algebra for DSP graph composition.

✅ **Acceptance Criteria:**
- Must allow combining signals using algebraic operations.
- Must correctly process audio signals through the composed graph.

🚫 **Out of Scope:**
- Graphical node-based editing interface.
